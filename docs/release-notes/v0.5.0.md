# Mon Noël v0.5.0 — Le fournil 🧁

## Nouveautés

- **Onglet Cuisine** avec deux parties :
  - **Mes recettes** : une bibliothèque toute simple — un nom, une photo, une catégorie et, si
    tu veux, le lien vers la vraie recette. Pas d'ingrédients ni d'étapes : ils restent dans ton
    application de recettes.
  - **Pour ce Noël** : ce que tu prépares cette année (sablés × 3 pour les voisins, une bûche
    pour le repas…), avec l'avancement **À faire → En cours → Faite** et la photo du résultat.
- **Le lutin** te propose « Préparer … » pour ce qui n'est pas encore fait, et coche tout seul
  quand c'est prêt.
- **Partage** : une page de recette partagée depuis le navigateur peut être rangée comme
  recette (nom, photo, lien).
- **Recherche** étendue aux recettes et aux préparations ; **accueil** avec la carte « Le fournil ».
- **Réglages** : catégories de recettes modifiables.

## Bon à savoir

- Les sauvegardes des versions précédentes restent importables.
- Les préparations des années passées gardent leur nom et leur photo, même si la recette change.
