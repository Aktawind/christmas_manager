# Checklist de test — v0.8.0 « Les traditions » ❤️

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.7.0.

## 1. Mise à jour

- [ ] Nouvel onglet **Traditions** (cœur) dans le menu ; les données sont intactes.
- [ ] Accueil : nouvelle carte **Nos traditions** ; « Traditions » a disparu des modules à venir.

## 2. Nos traditions

- [ ] Traditions a **trois onglets** : Au programme · Nos traditions · Inspirations.
- [ ] « 💡 Piocher des idées (52) » : une liste d'idées à cocher (« Tout cocher » possible) →
      « Ajouter » → elles rejoignent tes traditions ; le compteur baisse.
- [ ] « + Tradition » : nom, photo, catégorie et période (listes déroulantes), avec qui,
      ❤️ favorite, notes → Enregistrer. Les favorites passent en tête de liste.
- [ ] Le cœur sur une carte met / retire des favoris.
- [ ] Modifier, supprimer une tradition (et ses souvenirs).

## 3. Le programme de Noël 2026

- [ ] Onglet **Au programme** vide : un bouton mène à « Nos traditions ».
- [ ] « + Au programme » sur une carte → elle apparaît dans l'onglet **Au programme**, rangée par période.
- [ ] Cocher la ligne → faite ; « x sur y faites » suit.
- [ ] Toucher la ligne → fenêtre souvenir : « Faite cette année », photo, petit mot → la ligne
      montre la photo et le mot. La carte affiche « Faite en 2026 », la fiche « Nos souvenirs ».
- [ ] « Au programme ✓ » retouché → retirée du programme.

## 4. Inspirations

- [ ] « + Inspiration » : type (Films, Dessins animés, Livres, Musiques, Sorties, Activités),
      titre, lien, photo, notes. Filtres par type en haut.
- [ ] « À faire cette année » → « Fait cette année ✓ » (vaut pour ce Noël seulement).
- [ ] Partager une page depuis le navigateur → **Ranger comme : Inspiration** → type → elle
      arrive dans Inspirations avec la photo de la page.

## 5. Navigation revue

- [ ] Plus d'onglets **Rechercher** ni **Ma liste**. La recherche s'ouvre avec la **loupe** en haut à
      droite de **Mes Noëls** (flèche retour pour revenir).
- [ ] **Cadeaux → Listes** : « 📤 À envoyer » et « 📥 J'attends », à cocher ; toucher une ligne
      ouvre la fiche de la personne.
- [ ] Réglages : « Suggestions du lutin » a disparu ; nouvelle ligne **Le chemin vers Noël**.
- [ ] Accueil : la carte « Ma liste » a disparu. « Les cadeaux » ouvre l'onglet Cadeaux ;
      « Le fournil » ouvre Cuisine → Préparations ; « La table de fête » ouvre Cuisine → Repas.
- [ ] Les comptes : sans budget global, pas de case « Budget » ; les postes sans montant
      (ex. aucun repas) n'apparaissent pas.

## 6. Le chemin vers Noël

- [ ] Accueil → « Mes dates » (ou Réglages → Le chemin vers Noël) : nom, jour, mois (novembre,
      décembre, janvier), emoji → Ajouter.
- [ ] La date apparaît dans le chemin, à sa place entre le 1er décembre, le 24 et le 25 (au-delà de
      5 étapes, le chemin défile de côté). La supprimer la retire.

## 7. Recherche, accueil, sauvegarde

- [ ] 🔍 le nom d'une tradition ou d'une inspiration → groupes « Traditions », « Inspirations ».
- [ ] Accueil → Nos traditions : « x sur y faites cette année » et les prochaines.
- [ ] Exporter puis importer → traditions, programme, souvenirs, inspirations et dates du chemin reviennent.
      Une sauvegarde v0.7.0 s'importe toujours.
- [ ] Année archivée : programme et « fait cette année » en lecture seule.
