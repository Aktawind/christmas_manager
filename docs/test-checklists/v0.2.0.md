# Checklist de test — v0.2.0 « La hotte » 🎁

Avant tout : **Réglages → Exporter mes données** (par prudence), puis installer l'APK
par-dessus la v0.1.0. Tes Noëls doivent être toujours là.

## 1. Mise à jour

- [ ] Après installation, les années créées en v0.1 sont toujours présentes.
- [ ] Un nouvel onglet **Cadeaux** (icône paquet) apparaît dans le menu.

## 2. Personnes

- [ ] Cadeaux → onglet Personnes → « Nouvelle personne » : prénom, nom, goûts, notes → Enregistrer.
      La fiche s'ouvre.
- [ ] Ajouter une **photo** depuis la galerie, puis depuis l'**appareil photo**. La photo s'affiche
      bien droite (pas couchée).
- [ ] « Modifier » : changer le prénom, retirer la photo → Enregistrer.
- [ ] **Liste de souhaits** : ajouter 2 souhaits, en cocher un (il est barré), en supprimer un.
- [ ] **Enveloppe** : saisir 50 → Enregistrer. La barre dorée apparaît (« X € prévus sur 50 € »).
- [ ] Dépasser l'enveloppe : le message reste doux (« Un peu au-delà de l'enveloppe »), rien en rouge.

## 3. Idées

- [ ] Onglet Idées → « Nouvelle idée » : titre, prix estimé (ex. `12,50`), catégorie, une ou
      plusieurs personnes, lien, boutique, photo → Enregistrer.
- [ ] « Ouvrir le lien ↗ » ouvre la page dans le navigateur.
- [ ] Une idée **sans personne** est possible.
- [ ] Filtrer les idées par catégorie avec les puces en haut.
- [ ] **Accueil → « ✨ Noter une idée »** : un titre suffit → « Idée notée ». Elle apparaît dans Idées.
- [ ] **Partage Android** : depuis le navigateur (ou l'appli d'une boutique) → Partager →
      « Mon Noël » → la fenêtre « Noter une idée » s'ouvre avec le lien → Noter.

## 4. Cadeaux

- [ ] Sur une idée → « Offrir à… » → choisir une personne : le cadeau apparaît dans l'onglet
      Cadeaux avec le titre, le prix et la photo de l'idée.
- [ ] Modifier ensuite l'idée (titre, prix) : **le cadeau ne change pas** (historique figé).
- [ ] « Nouveau cadeau » → « 💡 Partir d'une idée » pré-remplit le formulaire.
- [ ] Remplir : destinataire, statut, prix, date d'achat (calendrier), catégorie, boutique, lien de
      commande, numéro de suivi, photo, notes → Enregistrer.
- [ ] **Changer le statut** depuis la liste : toucher le badge → menu déroulant → choisir.
      « Acheté en magasin » place directement le cadeau en « À emballer ».
- [ ] Passer un cadeau en « Commandé » : la date d'achat se remplit toute seule.
- [ ] Vues : **Par personne / Par statut / Par catégorie**.
- [ ] Filtres : **Achetés / À emballer / Pas encore reçus**.
- [ ] Le bandeau du haut affiche Prévu / Dépensé / Enveloppes / nombre de cadeaux, et se met à jour.
- [ ] Supprimer un cadeau (icône corbeille, confirmation).

## 5. Fiche personne, historique

- [ ] La fiche montre les cadeaux de l'année affichée et les idées pour cette personne.
- [ ] Créer un « Noël 2025 » (Mes Noëls), l'afficher, y ajouter un cadeau pour la même personne,
      puis revenir à 2026 : la fiche montre « Les Noëls précédents » avec le cadeau 2025.
- [ ] Archiver 2025 et l'afficher : les cadeaux se consultent mais ne se modifient plus.

## 6. Catégories

- [ ] Réglages → **Catégories de cadeaux** : ajouter, renommer, supprimer une catégorie.
- [ ] Supprimer une catégorie utilisée : les idées/cadeaux passent « Sans catégorie ».

## 7. Accueil

- [ ] La carte « Les cadeaux » résume : nombre, total prévu, à acheter / en livraison / à emballer
      / offerts. La toucher ouvre l'onglet Cadeaux.

## 8. Sauvegarde

- [ ] Exporter, supprimer une personne, restaurer : tout revient, **photos comprises**.
- [ ] Restaurer une sauvegarde faite en v0.1.0 : elle s'importe (catégories par défaut ajoutées).

## 9. Impressions

- [ ] Saisir un cadeau ou changer un statut est rapide et agréable.
- [ ] Rien ne passe sous les barres du haut et du bas (portrait et paysage).

## Retours du test 1 (corrigés dans le test 2)

- [ ] « ✨ Noter une idée » (accueil et partage Android) : on peut choisir **pour qui** est l'idée.
- [ ] Cadeaux groupés par personne : chaque personne a un **bandeau** (photo, nom, enveloppe,
      nombre de cadeaux) et une séparation dorée avec la personne suivante.
- [ ] Noms de groupes et titres de sections en **police classique** (plus de « Times »).
- [ ] Onglet Personnes : photos plus grandes.
- [ ] Onglet Idées : **cartes compactes**, photo plus grande, bouton 🎁 pour « Offrir à… ».
- [ ] Réglages : **Apparence en liste déroulante** ; **Catégories de cadeaux** dans un sous-écran.
