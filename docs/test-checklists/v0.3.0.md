# Checklist de test — v0.3.0 « Les calendriers de l'Avent » 🗓️

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.2.0.
Tes Noëls, personnes, idées et cadeaux doivent être toujours là.

## 1. Mise à jour

- [ ] Un nouvel onglet **Avent** apparaît dans le menu.
- [ ] Les données de la v0.2.0 sont intactes.

## 2. Créer un calendrier

- [ ] Avent → « Nouveau calendrier » : nom, personnes (une ou plusieurs), nombre de cases (24 par
      défaut, essayer 25), budget, thème, photo de couverture, description, notes → Enregistrer.
      Le calendrier s'ouvre avec la bonne grille.
- [ ] La liste montre une carte par calendrier avec « x / 24 cases prêtes ».

## 3. Les cases

- [ ] Toucher une case : choisir le type de surprise, écrire le contenu, prix, fournisseur, lien,
      photo, notes, avancement (À trouver / À préparer / Prête) → Enregistrer.
- [ ] La couleur de la case change selon l'avancement (○ à trouver, ● à préparer, ✓ prête).
- [ ] **Glisser-déposer** : appui long sur une case, la faire glisser sur une autre → elles
      échangent leur contenu (les numéros restent en place).
- [ ] « Seulement ce qui reste à faire » masque les cases prêtes.
- [ ] « 📋 Reprendre une case existante » copie le contenu d'une case d'un autre calendrier ou
      d'un modèle.

## 4. Fournitures et achats groupés

- [ ] « + Ajouter une fourniture » : nom, quantité, prix, déjà achetée.
- [ ] Un paquet de chocolats à 12 € réparti sur 12 cases : chaque case remplie affiche sa part.
- [ ] Cocher / décocher « achetée » directement dans la liste.
- [ ] L'en-tête montre Prévu / Dépensé / Budget et se met à jour.

## 5. Modifier le calendrier

- [ ] ✏️ : changer le nom, les personnes, le thème… Passer de 24 à 25 cases ajoute la case 25.
- [ ] Réduire le nombre de cases alors que les dernières sont remplies : un avertissement
      s'affiche avant.

## 6. Réutiliser

- [ ] ⋮ → « Enregistrer comme modèle » : le modèle apparaît dans « Mes modèles » (liste Avent).
- [ ] « Nouveau calendrier » → « À partir d'un de mes modèles » : le contenu des cases est repris.
- [ ] Créer un « Noël 2025 » avec un calendrier, revenir à 2026 → « Copier un calendrier d'une autre
      année » : tout est copié, toutes les cases repartent « À trouver ».
- [ ] Supprimer un modèle (corbeille).

## 7. Accueil

- [ ] La carte « Les calendriers de l'Avent » montre l'avancement de chaque calendrier.
- [ ] (À partir du 1er décembre) « Aujourd'hui, case n°X : … » s'affiche pour chaque calendrier.

## 8. Archives et sauvegarde

- [ ] Un calendrier d'une année archivée se consulte mais ne se modifie plus.
- [ ] Exporter, supprimer un calendrier, restaurer : il revient avec ses cases, photos et
      fournitures.
- [ ] Une sauvegarde faite en v0.2.0 s'importe toujours.

## 9. Impressions

- [ ] La grille est lisible en paysage et en portrait.
- [ ] Préparer les cases est agréable et rapide.
