# Checklist de test — v0.1.0 « Les fondations »

Appareil : tablette Android, en paysage **et** en portrait.
Coche chaque ligne ; note ce qui ne va pas (même un détail de couleur ou de texte).

## 0. Installation

- [ ] L'APK s'installe (autoriser l'installation depuis cette source si Android le demande).
- [ ] L'icône « Mon Noël » (sapin crème et or sur fond vert) apparaît dans les applications.
- [ ] Au lancement, l'écran de démarrage vert avec le sapin s'affiche brièvement.

## 1. Premier lancement

- [ ] L'écran « Bienvenue dans Mon Noël » s'affiche (fond vert, étoiles dorées).
- [ ] Le bouton indique « Commencer mon Noël 2026 ».
- [ ] Toucher ce bouton ouvre l'accueil.

## 2. Accueil

- [ ] « Noël 2026 » s'affiche avec le nombre de jours avant Noël (44 le 11 novembre, 43 le 12…).
- [ ] Une phrase douce s'affiche entre deux lignes dorées (elle change chaque jour).
- [ ] La section « Bientôt dans ton carnet » montre les 9 modules à venir, avec leur version.
- [ ] Sur tablette, le menu est sur le côté gauche ; en portrait aussi, rien n'est coupé.

## 3. Mes Noëls

- [ ] « Nouveau Noël » propose 2027 ; le créer → message « Noël 2027 est prêt ».
- [ ] Essayer de recréer 2026 → message « Le Noël 2026 existe déjà ».
- [ ] Une année invalide (ex. 1990) → le bouton « Créer » est grisé et une aide s'affiche.
- [ ] Toucher une carte → l'accueil affiche ce Noël (le compte à rebours suit l'année choisie).
- [ ] Menu ⋮ → « Archiver » : le badge « Archivé » apparaît ; l'accueil indique « Année archivée ».
- [ ] Menu ⋮ → « Désarchiver » : le badge disparaît.
- [ ] Créer une année passée (ex. 2025) et l'afficher → l'accueil dit « Noël 2025 est passé ».
- [ ] Menu ⋮ → « Supprimer » : une confirmation est demandée ; l'année disparaît.

## 4. Apparence

- [ ] Réglages → « Sombre (nuit de Noël) » : toute l'application passe en vert nuit, textes crème.
- [ ] « Clair » : retour à l'ivoire et au vert sapin.
- [ ] « Comme le système » : suit le thème de la tablette.
- [ ] Le choix est conservé après avoir fermé et rouvert l'application.

## 5. Export et restauration (le plus important)

- [ ] Réglages → « Exporter mes données » → choisir un emplacement (ex. Téléchargements ou Drive)
      → message « Sauvegarde exportée ». Le fichier `mon-noel-AAAA-MM-JJ-HHmmss.zip` existe.
- [ ] Supprimer une année, puis « Restaurer une sauvegarde » → choisir le fichier.
      La fenêtre indique la date de la sauvegarde et le nombre de Noëls → « Restaurer ».
      L'année supprimée est revenue.
- [ ] Choisir un fichier qui n'est pas une sauvegarde (une photo, un PDF) → message
      « Ce fichier n'est pas une sauvegarde Mon Noël », rien n'est modifié.
- [ ] **Test du changement d'appareil** : exporter, **désinstaller** l'application, la réinstaller.
      Sur l'écran de bienvenue → « Restaurer une sauvegarde » → tout est revenu.

## 6. Sauvegarde automatique

- [ ] Réglages → « Choisir un dossier » → créer/choisir un dossier (ex. `Documents/MonNoel`)
      → message « Dossier enregistré, première sauvegarde faite ».
- [ ] Le dossier et la date de la dernière sauvegarde s'affichent.
- [ ] « Sauvegarder maintenant » → un nouveau fichier `mon-noel-auto-…zip` apparaît dans le dossier.
- [ ] L'interrupteur « Sauvegarde quotidienne » peut être coupé et réactivé.
- [ ] (Le lendemain) une nouvelle sauvegarde automatique a été faite sans rien toucher.

## 7. Mise à jour sans perte

- [ ] Quand je t'enverrai un nouvel APK de test, l'installer **par-dessus** : les données sont conservées.

## 8. Impressions générales

- [ ] L'ambiance est chaleureuse, pas « outil de travail ».
- [ ] Les textes sont lisibles (taille, contraste), en clair comme en sombre.
- [ ] Rien ne bloque, rien ne plante.
