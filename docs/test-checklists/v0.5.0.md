# Checklist de test — v0.5.0 « Le fournil » 🧁

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.4.0.

## 1. Mise à jour

- [ ] Nouvel onglet **Cuisine** (petit gâteau) dans le menu. Les données sont intactes.
- [ ] Accueil : « Pâtisseries & recettes » a disparu des modules à venir ; nouvelle carte
      **Le fournil** (« Rien de prévu pour l'instant… »).

## 2. Mes recettes (bibliothèque)

- [ ] Cuisine → **Mes recettes** → « + Recette » : nom, photo (galerie ou appareil photo),
      catégorie (liste déroulante), lien facultatif → Enregistrer. **Pas d'ingrédients, pas d'étapes.**
- [ ] Les recettes s'affichent en cartes compactes avec la photo ; filtres par catégorie en haut
      (seules les catégories utilisées apparaissent).
- [ ] Avec un lien : « Ouvrir la recette » ouvre le site.
- [ ] Supprimer une recette (corbeille).

## 3. Pour ce Noël (préparations)

- [ ] Depuis une recette : **« Préparer pour Noël 2026 »** → la fiche de préparation s'ouvre,
      déjà remplie avec la recette.
- [ ] « + À préparer » : choisir une recette **ou** « Aucune (nom libre) » et écrire un nom.
- [ ] Quantité avec − / + ; « Pour qui / pour quoi » avec les raccourcis (Voisins, École…).
- [ ] Avancement **À faire → En cours → Faite** dans la fiche **et** directement dans la liste
      (menu déroulant à droite de chaque ligne).
- [ ] La liste est rangée par avancement ; en haut « x sur y préparés ».
- [ ] Sans photo du résultat, la photo de la recette est utilisée ; ajouter une photo du
      résultat la remplace.
- [ ] Modifier ou supprimer la recette ensuite **ne change pas** la préparation (nom, photo).

## 4. Le lutin, la recherche, l'accueil

- [ ] Ma liste : suggestion « Préparer « Sablés… » × 3 » pour chaque préparation pas faite.
      L'ajouter, puis passer la préparation en « Faite » → la tâche se coche seule.
- [ ] Réglages → Suggestions du lutin : « Préparer les pâtisseries prévues » peut être désactivé.
- [ ] 🔍 : taper le nom d'une recette ou d'une préparation → groupes « Recettes » et
      « Préparations » ; toucher un résultat ouvre la fiche.
- [ ] Accueil → **Le fournil** : « x sur y préparés » et les prochaines ; toucher la carte
      ouvre Cuisine.

## 5. Partage depuis le navigateur

- [ ] Partager une page de recette vers Mon Noël → dans la fenêtre, **Ranger comme : Recette**
      → le prix et les personnes disparaissent → Enregistrer → la recette est dans
      Mes recettes avec la photo de la page (si le site la donne) et le lien.
- [ ] Le partage d'une idée cadeau fonctionne toujours comme avant.

## 6. Réglages et sauvegarde

- [ ] Réglages → **Catégories de recettes** : ajouter, renommer, supprimer (les recettes
      deviennent « sans catégorie »).
- [ ] Exporter, puis importer la sauvegarde → recettes, catégories et préparations reviennent.
- [ ] Une sauvegarde de la v0.4.0 s'importe toujours (catégories de recettes ajoutées).
- [ ] Année archivée : les préparations sont en lecture seule.
