# Checklist de test — v0.9.0 « L'atelier des lutins » ✂️

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.8.0.

## 1. Mise à jour

- [ ] Les données sont intactes. Traditions a maintenant **cinq onglets** (ils défilent sur
      téléphone) : Au programme · Nos traditions · Inspirations · Bricolages · Décoration.
- [ ] Accueil : nouvelle carte **L'atelier** ; « Activités, DIY & déco » a disparu des modules à venir.

## 2. Dépassements de budget (correctif)

- [ ] Cadeaux : une personne au-delà de son enveloppe → la barre est un peu plus **orangée**,
      **aucune note** dessous ; les cartes restent alignées.
- [ ] Les comptes : un poste ou le budget global dépassé → même barre orangée, sans texte de dépassement.
- [ ] Accueil → Les comptes : idem.

## 3. Bricolages

- [ ] Onglet **Bricolages** vide : un message explique ; « 💡 Piocher des idées (15) » → cocher →
      Ajouter → les bricolages arrivent **avec leurs fournitures** ; le compteur baisse.
- [ ] « + Bricolage » : nom, photo, catégorie (liste déroulante), lien du tutoriel, notes.
      Avec un lien commençant par http, « Ouvrir le tutoriel » ouvre le navigateur.
- [ ] Fournitures : nom + prix (facultatif) → « + » ; la croix retire une fourniture.
- [ ] « Noël 2026 → Avancement » : Idée, Au programme, En cours, Terminé. En « Terminé », ajouter
      la **photo du résultat** : elle remplace la photo sur la carte.
- [ ] Dès qu'il est au programme, les fournitures se **cochent** (acheté). La carte affiche « 1/4 fournitures ».
- [ ] Sur la carte, la puce d'avancement ouvre la liste des choix (sans ouvrir la fiche).
- [ ] Filtres en haut : Tout · Idée · Au programme · En cours · Terminé. Toutes les cartes ont la même hauteur.
- [ ] Terminé deux années → « Fait en 2025, 2026 » (carte et fiche → « Déjà fait »).
- [ ] Supprimer un bricolage (corbeille, confirmation).

## 4. Décoration

- [ ] « + Déco » : photo, pour (Sapin, Table de fête, Entrée, Fenêtres, Extérieur, Autre),
      titre (facultatif si photo), lien, commentaire, ❤️ favorite → Enregistrer.
- [ ] Grille de photos ; le cœur met / retire des favoris (favorites en tête).
- [ ] Filtres : Tout · ❤️ Favorites · par endroit.
- [ ] Toucher une carte → modifier ou supprimer.
- [ ] Partager une page depuis le navigateur → **Ranger comme : Déco** → endroit → elle arrive
      dans Décoration avec la photo de la page.

## 5. Les comptes

- [ ] Nouveau poste **✂️ Atelier** (violet) : prévu = prix des fournitures des bricolages au
      programme (en cours ou terminés compris) ; dépensé = celles cochées.
- [ ] Un bricolage remis en « Idée » sort du budget de l'année.

## 6. Recherche, accueil, sauvegarde

- [ ] 🔍 un bricolage, **une fourniture** (ex. « ruban ») ou une déco → groupes « Bricolages » et
      « Décoration » ; toucher ouvre la fiche / la fenêtre.
- [ ] Accueil → L'atelier : « x sur y terminés » et les prochains ; toucher ouvre Traditions → Bricolages.
- [ ] Exporter puis importer → bricolages, fournitures, avancement, photos et déco reviennent.
      Une sauvegarde v0.8.0 s'importe toujours.
- [ ] Année archivée : avancement et fournitures en lecture seule (la bibliothèque reste modifiable).
