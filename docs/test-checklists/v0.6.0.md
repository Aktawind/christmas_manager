# Checklist de test — v0.6.0 « La table de fête » 🍽️

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.5.0.

## 1. Mise à jour

- [ ] Cuisine a maintenant trois onglets : **Repas** · Gourmandises (les préparations de la
      v0.5) · Mes recettes. Les données sont intactes.
- [ ] Accueil : nouvelle carte **La table de fête** ; « Repas » a disparu des modules à venir.

## 2. Un repas

- [ ] Cuisine → Repas → « + Repas » : choisir le type **Réveillon du 24** → le nom
      « Réveillon » et la date du 24 décembre sont proposés. Passer à **Déjeuner du 25** → ils
      changent ; les modifier à la main → ils ne changent plus.
- [ ] Date : choisir une autre date, puis « Sans date ».
- [ ] Lieu, notes, **coût estimé** (ex. 150) → Enregistrer → la fiche du repas s'ouvre.
- [ ] **Convives** : cocher des personnes de l'app, ajouter « Oncle Paul » en invité libre,
      le retirer avec la croix. Le compteur « Convives · N » suit.
- [ ] La carte du repas montre date, lieu, nombre de convives, de plats et le coût.

## 3. Le menu

- [ ] Un **Goûter** n'a que **Sucré** et **Boissons** ; un **Brunch** : Salé, Sucré, Boissons.
- [ ] « Ajouter un moment » (en bas) ajoute par exemple « Salé » ; la croix à côté d'un moment
      vide le retire (un moment qui a des plats ne peut pas être retiré).

- [ ] Dans la fiche : « + Ajouter » à côté de **Entrée** → le moment est déjà choisi.
- [ ] Plat tiré de **Mes recettes** (la photo s'affiche) ou **nom libre**.
- [ ] « Qui apporte ? » → « Apporté par Mamie » sous le plat.
- [ ] **À commander** : activer → bouton « À commander » sur la ligne ; le toucher → « Commandé ✓ ».
- [ ] Modifier / supprimer un plat ; modifier le repas (crayon) ; supprimer le repas.

## 4. Retours de la v0.6.0-test1

- [ ] Accueil : la ligne du **chemin vers Noël** est bien droite.
- [ ] « Ma liste de lutin » s'appelle maintenant **Ma liste** (onglet, titre, accueil).
- [ ] Fiche d'une personne : les idées montrent leur **photo** ; toucher une idée →
      « 🎁 En faire un cadeau pour Noël 2026 » → le cadeau apparaît au-dessus ; ou « Modifier l'idée ».
- [ ] Calendrier : plus de note d'aide ni de bouton « Sélectionner plusieurs cases ».
      **Appui long** sur une case → elle est sélectionnée, la barre du haut affiche « 1 case(s)
      sélectionnée(s) », Toutes, Les vides, Modifier… Toucher d'autres cases les ajoute ; la croix
      ou le bouton retour quitte la sélection.
- [ ] **Appui long puis glisser** une case sur une autre → elles s'échangent (pas de sélection).
- [ ] Fournitures et achats groupés : plus de note sous le titre.

## 5. Le lutin, la recherche, l'accueil

- [ ] Un repas sans plat → suggestion « Préparer le menu « … » ». Ajouter un plat → elle se coche.
- [ ] Un plat à commander → « Commander « Huîtres » (Réveillon) ». Marquer commandé → cochée.
- [ ] Réglages → Suggestions du lutin : les deux nouveaux types peuvent être désactivés.
- [ ] 🔍 « huîtres » → le repas Réveillon est trouvé, avec le plat en sous-titre.
- [ ] Accueil → **La table de fête** : prochain repas, convives, plats, plats à commander.
