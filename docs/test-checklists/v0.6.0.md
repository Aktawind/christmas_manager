## 1. Mise à jour

- [ ] Cuisine a maintenant trois onglets : **Repas** · Gourmandises (les préparations de la
      v0.5) · Mes recettes. Les données sont intactes.
- [ ] Accueil : nouvelle carte **La table de fête** ; « Repas » a disparu des modules à venir.

## 2. Un repas

- [ ] Cuisine → Repas → « + Repas » : choisir le type **Réveillon du 24** → le nom
      « Réveillon » et la date du 24 décembre sont proposés. Passer à **Déjeuner du 25** → ils
      changent ; les modifier à la main → ils ne changent plus.
- [ ] Date : choisir une autre date, puis « Sans date ».
- [ ] Lieu, notes, **coût estimé** (ex. 150) → Enregistrer → la fiche du repas s'ouvre.
- [ ] **Convives** : cocher des personnes de l'app, ajouter « Oncle Paul » en invité libre,
      le retirer avec la croix. Le compteur « Convives · N » suit.
- [ ] La carte du repas montre date, lieu, nombre de convives, de plats et le coût.

## 3. Le menu

- [ ] Dans la fiche : « + Ajouter » à côté de **Entrée** → le moment est déjà choisi.
