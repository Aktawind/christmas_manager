# Checklist de test — v0.7.0 « Les comptes du Père Noël » 💰

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.6.0.

## 1. Mise à jour

- [ ] Nouvel onglet **Budget** (porte-monnaie) entre « Ma liste » et « Mes Noëls ».
- [ ] Accueil : nouvelle carte **Les comptes** ; « Budget » a disparu des modules à venir.

## 2. Le budget de l'année

- [ ] En haut : **Prévu**, **Dépensé**, **Budget**. Sans budget : un petit texte l'explique.
- [ ] « Fixer un budget » (ex. 800) → barre dorée et « Encore … de marge ». Le baisser sous le
      prévu → « … au-dessus du budget » en bordeaux discret, sans alerte. « Retirer » l'enlève.
- [ ] **Répartition du prévu** : une barre en 4 couleurs et, dessous, chaque poste avec prévu et
      dépensé. Vérifier les montants :
  - Cadeaux = somme des prix ; dépensé = cadeaux commandés, achetés ou plus loin ;
    « Enveloppes : … » et « … au-dessus » si le prévu dépasse les enveloppes.
  - Calendriers = cases + fournitures, comme sur l'écran du calendrier.
  - Repas = coûts estimés ; un repas compte comme dépensé à partir de sa date.
  - Autres dépenses = leurs montants ; dépensé = celles cochées « payé ».

## 3. Autres dépenses

- [ ] « + Dépense » : catégorie (Sapin, Décoration, Papier cadeau, Tenues, Sorties, Divers) → le
      nom se propose ; montant, « C'est payé », notes → Enregistrer.
- [ ] Cocher / décocher « payé » directement dans la liste → le dépensé change.
- [ ] Modifier, supprimer une dépense.

## 4. D'une année à l'autre

- [ ] Avec au moins deux Noëls qui ont des montants : « Coût prévu de chaque Noël » en colonnes,
      avec la valeur au-dessus et l'année dessous.

## 5. Recherche, thème, sauvegarde

- [ ] 🔍 « sapin » → la dépense est trouvée ; la toucher ouvre le Budget avec la dépense.
- [ ] Thème sombre : couleurs des graphiques lisibles.
- [ ] Exporter puis importer → autres dépenses et budget global reviennent. Une sauvegarde
      v0.6.0 s'importe toujours.
- [ ] Année archivée : budget consultable, dépenses en lecture seule.
