# Checklist de test — v0.4.0 « Ma liste de lutin » 📝

Avant tout : **Réglages → Exporter mes données**, puis installer l'APK par-dessus la v0.3.0.

## 1. Mise à jour

- [ ] Deux nouveaux onglets : **Rechercher** 🔍 et **Ma liste**. Les données sont intactes.

## 2. Ma liste

- [ ] « Nouvelle chose à faire » : titre, thème (Cadeaux, Calendriers, Maison & déco…), où j'en
      suis, détails, notes → Enregistrer. **Aucune date, aucune priorité.**
- [ ] Les tâches sont rangées par thème ; cocher une tâche la barre, décocher la remet à faire.
- [ ] Filtres : À faire / Faites / Tout.
- [ ] Supprimer une tâche (corbeille).

## 3. Les suggestions du lutin

- [ ] Mettre un cadeau en « Commandé » → « Vérifier la livraison de … » apparaît dans les
      suggestions. « À emballer » → « Emballer … ». Une fourniture non achetée → « Acheter … ».
      Des cases à trouver ou à préparer → « Trouver N surprises… », « Préparer N cases… ».
- [ ] « Ajouter » met la suggestion dans la liste ; « ✕ » la supprime (elle ne revient pas).
      « Tout ajouter » ajoute tout d'un coup.
- [ ] Toucher le texte d'une suggestion ouvre le cadeau ou le calendrier concerné.
- [ ] **Coche automatique** : passer le cadeau en « Reçu » → « Vérifier la livraison » se coche
      toute seule. Le repasser en « Commandé » → elle redevient à faire.
- [ ] Réglages → **Suggestions du lutin** : désactiver un type → ses suggestions disparaissent.

## 4. Recherche

- [ ] 🔍 : taper un prénom, une idée, un cadeau, un calendrier, le contenu d'une case, une tâche.
      Les résultats sont regroupés par catégorie ; les accents et majuscules ne comptent pas.
- [ ] Les cases identiques d'un calendrier (ex. « Chocolat ») ne font qu'une ligne avec leurs numéros.
- [ ] Toucher un résultat ouvre l'élément.
- [ ] Les cadeaux des années passées sont trouvés (avec l'année).

## 5. Accueil

- [ ] **Le chemin vers Noël** : 1er décembre (calendriers), 24 (réveillon), 25 (Noël) ; l'étape
      suivante est mise en avant, les étapes passées en doré. Aucun « retard ».
- [ ] La carte **Ma liste de lutin** montre l'avancement (cadeaux emballés ou offerts, cases
      prêtes, choses faites), les prochaines choses à faire et le nombre de suggestions.

## 6. Sauvegarde

- [ ] Exporter, supprimer une tâche, restaurer : elle revient. Les suggestions supprimées
      restent supprimées.
- [ ] Une sauvegarde de la v0.3.0 s'importe toujours.
