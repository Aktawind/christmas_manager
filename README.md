# 🎄 Mon Noël

Application Android pour préparer Noël sans subir les préparatifs : idées, cadeaux,
calendriers de l'Avent, recettes, repas, petites listes de choses à faire, budget,
traditions, activités, décoration et souvenirs — année après année, hors connexion.

- Décisions : [docs/decisions/](docs/decisions/)
