# 🎄 Carnet de Noël

Application Android pour préparer Noël sans subir les préparatifs : idées, cadeaux,
calendriers de l'Avent, recettes, repas, planning, budget, traditions, activités,
décoration et souvenirs — année après année, hors connexion.

- Feuille de route : [docs/ROADMAP.md](docs/ROADMAP.md)
- Décisions : [docs/decisions/](docs/decisions/)
- Conventions du projet : [CLAUDE.md](CLAUDE.md)

## Installer une version

- **Version validée** : onglet *Releases* → dernière version `vX.Y.Z` → fichier `.apk`.
- **Version de test** : pré-version `develop-latest` (application « Carnet de Noël β »,
  installable à côté de la version validée).
